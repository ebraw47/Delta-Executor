# About Delta Executor

**Delta Executor** is a popular, predominantly mobile-focused (Android & iOS) third-party tool designed to run custom Lua scripts within Roblox games to alter gameplay or automate tasks. It works by injecting these scripts into the Roblox app, allowing users to unlock features or gain advantages—operating similarly to a mod menu.

This site ([deltaexecutor.com.tr](/)) publishes download and setup guides for Delta across Android, iOS, VNG, Windows, and Mac — plus Direct Install, keys, Premium, and common fixes.

## How It Generally Works

- **Script injection** — Delta sits as a layer on Roblox and injects custom code so user Lua can run in-game.
- **Mobile first** — Android APK installs are the most common path; iOS uses Direct Install or sideloaded IPA when available.
- **PC** — Players use a Windows build when published, or run the Android APK in an emulator.
- **Key unlock** — Free users typically complete a Receive Key / checkpoint flow (~24 hours per key on builds we document). [Premium](/delta-executor-premium) can remove the daily loop.

## Typical Use Flow

1. Download the installer from this site’s [hub](/#download)
2. Sideload / trust the install (unknown sources, iOS profile, or Gatekeeper)
3. Complete the [key system](/delta-executor-key) when prompted
4. Join a game, open the Delta menu, paste a script, and execute
