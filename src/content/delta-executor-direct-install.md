# Delta Executor Direct Install — iOS Guide

**Direct Install** is the quickest way to put Delta Executor on an iPhone or iPad without a separate sideloading app. You install from this site’s hub, trust the enterprise profile, restart, then open Delta.

For broader iOS options (IPA + sideload), see the [iOS guide](/delta-executor-ios). Downloads stay on **deltaexecutor.com.tr** — no third-party download doors.

## Who Should Use Direct Install?

- Players who want Delta on **iOS** with the fewest tools
- Anyone tired of importing IPAs into ESign / KSign for every update
- Users who already tried sideloading and want the simpler path

If free certificates revoke often on your device, read [Premium](/delta-executor-premium) after you understand the free flow.

## Step-by-Step Direct Install

1. Open Safari (or your usual browser) and go to the [homepage download hub](/#download).
2. Tap **Direct Install**. The installer file is served from this domain.
3. When iOS shows the install prompt, confirm **Install**.
4. Wait until Delta appears on the Home Screen.
5. Open **Settings → General → VPN & Device Management** (wording can vary slightly by iOS version).
6. Select the enterprise app / developer entry shown for Delta and tap **Trust**.
7. Restart the device if prompted.
8. Launch Delta. If a key is required, follow the [key guide](/delta-executor-key).
9. For smoother inject performance on iPhone, follow the [iOS performance step-by-step post](/delta-executor-ios-performance).

## First Launch Checklist

- Roblox is installed and you can join a game
- The enterprise profile is trusted (not just installed)
- You completed or skipped the key flow correctly
- You are on a global Roblox account unless you intentionally use [VNG](/delta-executor-vng)

## When Direct Install Stops Working

Free Direct Install can stop launching after Apple or the signing profile revokes. Typical fixes:

1. Delete the old Delta app.
2. Return to this site and run Direct Install again from the hub.
3. Re-trust the new profile under VPN & Device Management.
4. If revokes happen constantly, compare options on [Premium](/delta-executor-premium).

Do not hunt random “Direct Install” Google results — many are phishing pages. Stay on **deltaexecutor.com.tr**.

## Direct Install vs Sideload

| --- | --- | --- |
| Extra apps | Usually none | ESign / KSign / similar |
| Speed | Fastest for most users | Extra steps |
| Stability | Can revoke on free certs | Depends on your signer |
| File | Hub Direct Install button | Hub iOS IPA button |
