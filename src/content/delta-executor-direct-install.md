# Delta Executor Direct Install — iOS Rehberi

**Direct Install**, Delta Executor’ı iPhone veya iPad’e ayrı bir sideload uygulaması olmadan kurmanın en hızlı yoludur. Bu sitenin hub’ından kurarsınız, kurumsal profile güvenirsiniz, yeniden başlatır, Delta’yı açarsınız.

Daha geniş iOS seçenekleri (IPA + sideload) için [iOS rehberine](/delta-executor-ios) bakın. İndirmeler **deltaexecutortr.com.tr** üzerinde kalır — üçüncü taraf indirme kapıları yok.

## Direct Install Kimler İçin?

- **iOS**’ta en az araçla Delta isteyen oyuncular
- Her güncellemede IPA’yı ESign / KSign’e aktarmaktan yorulanlar
- Sideload denemiş ve daha basit yol isteyenler

Cihazınızda ücretsiz sertifikalar sık iptal oluyorsa ücretsiz akışı öğrendikten sonra [Premium](/delta-executor-premium) okuyun.

## Direct Install Adım Adım

1. Safari (veya alışık olduğunuz tarayıcı) ile [ana sayfa indirme hub’ına](/#download) gidin.
2. **Direct Install**’a dokunun. Kurulum dosyası bu alandan sunulur.
3. iOS kurulum isteminde **Install** (Yükle) onaylayın.
4. Delta Ana Ekran’da görünene kadar bekleyin.
5. **Ayarlar → Genel → VPN ve Cihaz Yönetimi**’ni açın (iOS sürümüne göre ifade hafif değişebilir).
6. Delta için gösterilen kurumsal uygulama / geliştirici girişini seçip **Trust** (Güven) verin.
7. İstenirse cihazı yeniden başlatın.
8. Delta’yı başlatın. Anahtar gerekirse [anahtar rehberini](/delta-executor-key) izleyin.
9. iPhone’da daha akıcı enjekte için [iOS performans adım adım yazısını](/delta-executor-ios-performance) takip edin.

## İlk Açılış Kontrol Listesi

- Roblox kurulu ve bir oyuna girebiliyorsunuz
- Kurumsal profile güvenildi (yalnızca kurulmuş değil)
- Anahtar akışı doğru tamamlandı veya atlandı
- Bilerek [VNG](/delta-executor-vng) kullanmıyorsanız global Roblox hesabındasınız

## Direct Install Çalışmayı Bıraktığında

Ücretsiz Direct Install, Apple veya imza profili iptal edildikten sonra açılmayabilir. Tipik çözümler:

1. Eski Delta uygulamasını silin.
2. Bu siteye dönüp hub’dan Direct Install’ı yeniden çalıştırın.
3. VPN ve Cihaz Yönetimi altında yeni profile yeniden güvenin.
4. İptaller sürekliyse [Premium](/delta-executor-premium) seçeneklerini karşılaştırın.

Rastgele “Direct Install” Google sonuçlarının peşine düşmeyin — çoğu kimlik avı sayfasıdır. **deltaexecutortr.com.tr** üzerinde kalın.

## Direct Install vs Sideload

| | Direct Install | Sideload (IPA) |
| --- | --- | --- |
| Ek uygulamalar | Genelde yok | ESign / KSign / benzeri |
| Hız | Çoğu kullanıcı için en hızlı | Ek adımlar |
| Kararlılık | Ücretsiz sertifikalarda iptal olabilir | İmzalayıcınıza bağlı |
| Dosya | Hub Direct Install düğmesi | Hub iOS IPA düğmesi |
